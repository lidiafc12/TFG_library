# Rule-based detect-and-avoid algorithm for Air Traffic Control

**Bachelor's Final Project · Aerospace Systems Engineering · Universitat Politècnica de Catalunya (UPC), 2022**
Grade: **9.6/10 · Honours (Matrícula de Honor)**

A conflict-resolution policy that keeps aircraft safely separated in a 2D airspace sector, based on the EASA Standardised European Rules of the Air (SERA). Built in Python on the EUROCONTROL Innovation Masterclass simulation environment.

## Results

Over **500 simulated episodes** (10 flights each), compared with the same scenarios without the policy:

| Metric | Result |
|---|---|
| Reduction in conflicts | **99.41%** (5 conflicts in 500 episodes) |
| Reduction in alerts | **87.95%** |

A sensitivity analysis measured how performance changes with the number of flights, alert distance and time, and the aircraft's turning limitation.

## How it works

Each simulation step, the policy:

1. **Detects** potential conflicts by computing the **Closest Point of Approach** (time and distance) between every pair of aircraft.
2. **Prioritises** them, solving the most urgent and severe ones first.
3. **Decides who gives way** by applying the **Right of Way** rules: head-on, converging and overtaking situations.
4. **Resolves** each conflict with heading changes, using **Remain Well Clear** guidance bands to choose safe angles while limiting extra distance flown.

Only lateral separation is used. Conflict distance is 5 NM.

## Project structure

```
main.py              # Runs the simulation with and without the policy and logs the metrics
atcenv/env.py        # 2D airspace environment (Gym)
atcenv/policy.py     # Detect-and-avoid policy: CPA, Right of Way, Remain Well Clear
atcenv/definitions.py
atcenv/units.py
```

## How to run

```bash
pip install -r requirements.txt
python main.py --episodes 500
```

Results are logged to Weights & Biases. To run without it, set `WANDB_USAGE = False` in `main.py`.

The dependency versions are from 2022 and work best with Python 3.8.
